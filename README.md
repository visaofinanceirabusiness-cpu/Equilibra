# Equilibra — Centro Holístico

Sitio web para Centro Holístico Equilibra (Jorge Buenaventura), masoterapia y terapias holísticas en Ingleses, Florianópolis.

Sitio estático (HTML/CSS/JS puro), sin dependencias ni build. Contenido en portugués por defecto con selector de idioma (PT / ES / EN).

## Estructura

- `index.html` — contenido y estructura de la página
- `styles.css` — estilos (paleta e identidad visual de la marca)
- `script.js` — selector de idioma y menú móvil

## Editar contenido

Los textos de cada idioma están en `script.js`, dentro del objeto `translations`. El contenido en portugués (idioma por defecto) también aparece directamente en `index.html`.

## Publicar

Al ser un sitio 100% estático, se puede desplegar en Vercel, Netlify o GitHub Pages sin ninguna configuración adicional: solo apuntar al repositorio.
